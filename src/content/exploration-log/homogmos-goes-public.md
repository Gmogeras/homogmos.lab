Homogmos Lab launched publicly on GitHub Pages. The site itself is now part of the experiment: research, code and communication can be developed in public rather than appearing only after completion.

The goal is to show work at multiple stages while keeping a clear boundary between preliminary analysis and peer-reviewed evidence.
